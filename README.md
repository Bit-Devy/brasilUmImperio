# Passos do Império

Site interativo sobre a história do Brasil Império, da Independência em 1822 à Proclamação da República em 1889. O percurso acontece em um tabuleiro com acontecimentos históricos, leituras e fontes de pesquisa.

**[Acessar o site](https://bit-devy.github.io/brasilUmImperio/)** · **[Pesquisa histórica e fontes](pesquisaHistorica.md)**

## Como usar

Com Node.js 20 ou superior, execute na pasta do projeto:

```sh
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) e use as setas do teclado ou os controles na tela para percorrer a história.

## Preparar para hospedagem

```sh
npm run build
```

Os arquivos do site serão gerados na pasta `dist/`.
